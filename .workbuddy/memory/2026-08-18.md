## commercial-trend 项目搭建（应用户要求，正交竞争项目）

- 定位：预测领域**商业化信号增长**（CSI = 仓库新建数 + SO 提问量 + 论文数），与对方的"词汇共现"正交。
- 数据源（全免 key）：OpenAlex group_by、GitHub Search API、Stack Exchange API。
- 算法：Kleinberg 两状态突发检测（Viterbi DP）、YoY/CAGR/z-score 动量、共现图链接预测指标组（CN/Jaccard/AA/PA/两跳有效电导作为基线）、逻辑回归 + StandardScaler + C=0.1 强正则。
- 评估：walk-forward 时间切分（无泄漏），四基线对比（full / graph_only / persistence / prior）。
- 输出：dist/index.html 静态看板（Chart.js），GitHub Actions 自动部署 Pages。
- 文件：pipeline/{topics,ingest,signals,model,site}.py + main.py + docs/THEORY.md + .github/workflows/pages.yml + README + LICENSE(MIT) + .gitignore + requirements.txt。
- WSL2 测试通过：sample 模式 48 样本，full AUC 0.715 vs graph_only 0.557（+0.158 增量），persistence 0.828（最强基线，诚实保留），Brier full 0.161 最佳。
- API 烟测：OpenAlex 与 Stack Exchange 客户端正常；GitHub 在当前网络超时（环境问题，非代码问题）。

## loomsci_lexicon 预测方法深度评判（sci_backtest_2016 + sci_predict2026）

读了 docs/sci_predict_reproduce.md 全文。结论：
- 方法本质：G(AB,t) 两跳有效电导的时间序列波动性 CV → 预测概念对首次共现。
- vs 其他方法：AUC 0.696 低于标准链接预测基线（AA/CN ~0.75+，动态嵌入 0.87）；卖点是可解释+免GPU，非精度。
- 自爆点：sci_backtest_fair.py 随机对照 0% 命中 → 文档自承"两跳采样先验是全部增益来源"，G-CV 只加边际。
- "无法作弊"不成立：特征层（G≤T0）成立，但超参数（CV 0.3-1.0、I 5-40）在 2015 回测上调出，2015/2016 两个回测结局窗口重叠 9 年 → 超参数层可作弊。
- 真正无法作弊需：预注册冻结 + 窗口不重叠 + 多T0 walk-forward + 强基线同台 + 哈希预提交 2026 预测。这正是 commercial-trend 项目刻意采用的协议。
